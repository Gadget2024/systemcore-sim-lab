WPILib 2027 Alpha 7 · desktop simulation

Connect your practice robot

  1. Install Java 25 JDK. Use Temurin 25 for your computer. Close and reopen your terminal after installation.
  2. Open a second terminal in this project folder. Keep the web server running in the first one. Run npm run robot. The first run downloads WPILib and can take several minutes.
  3. Wait for “Robot program startup complete”. This page connects automatically. You can then choose a lesson and enable the robot.

No robot, controller, team number, or separate Gradle install is needed. Full setup and troubleshooting
